# 回答：证据、引用与拒答

> 本页保留旧 URL 与原导读练习，作为迁移入口。完整正文已迁至：[18 带引用的答案，真的有依据吗](../04-grounded/18-evidence.md)、[21 权限隔离与文档中的恶意指令](../04-grounded/21-security.md)。以下是历史导读，不代表当前示例的覆盖范围；运行与验收以新正文为准。

## 场景与目标

检索命中了旧版文档，模型给出新版 API 用法却附上旧版链接。

## 从前端经验出发

像展示服务端数据来源一样，让结论、引用与适用版本关联。

## 类比的边界

有引用不等于引用支持结论；RAG 不能保证消除幻觉。

## 实现思路

要求回答基于可用证据；检查引用 ID 存在、版本匹配，并评测证据支持性；证据不足时澄清、返回检索结果或拒答。

## 练习

加入无答案、版本冲突与只有部分证据的问题。

## 验收

不编造引用；版本冲突可见；无答案行为稳定；分别评测检索命中与回答忠实度。
