# 执行循环：状态机、预算与恢复

> 本页保留旧 URL 与原导读练习，作为迁移入口。完整正文已迁至：[27 一个受限的 Agent 循环](../06-agent/27-bounded-loop.md)、[28 任务中断以后，如何安全继续](../06-agent/28-recovery.md)、[30 复盘一次失败的 Agent 任务](../06-agent/30-failure-review.md)。以下是历史导读，不代表当前示例的覆盖范围；运行与验收以新正文为准。

## 场景与目标

Agent 连续搜索却找不到答案，仍不停调用模型。

## 从前端经验出发

像管理复杂异步页面一样，为任务、步骤、工具结果与终止条件建立状态机。

## 类比的边界

恢复不能简单重放所有步骤；外部写入不一定可撤销，检查点与真实世界可能不一致。

## 实现思路

定义目标、最大回合、时间和费用预算；每步记录输入与结果；对重复行动检测无进展；持久化检查点并校验副作用状态再恢复。

## 练习

注入工具失败、进程中断和重复搜索。

## 验收

所有任务都能在预算内结束；失败原因可解释；恢复不重复执行已完成写入。
