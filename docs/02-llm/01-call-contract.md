# LLM 调用契约与结构化输出

> 本章为学习导读与实践要求，后续补充可运行实现。

## 场景与目标

页面需要展示组件名称、参数与来源，模型却返回一段不稳定的自由文本。

## 从前端经验出发

把模型适配层视为接口适配器，为输入、输出、流式事件和错误建立明确契约。

## 类比的边界

JSON 解析或 schema 校验只验证形状，不验证组件存在、参数真实或引用可靠。

## 实现思路

定义最小输出 schema；逐层做解析、结构与业务校验；流式片段按协议组装，完成后再验证整体；不完整结果不能驱动副作用。

## 练习

构造缺字段、截断、拒答、错误组件名与错误来源样例。

## 验收

有效结果才进入业务流程；无效结果有明确恢复路径；不同供应商差异被适配层隔离。
