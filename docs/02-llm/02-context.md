# 上下文与 Prompt：管理输入依赖

> 本章为学习导读与实践要求，后续补充可运行实现。

## 场景与目标

对话越来越长，费用上升，旧约束开始干扰新问题。

## 从前端经验出发

借鉴状态管理与依赖注入，区分任务目标、规则、历史、检索证据和工具结果。

## 类比的边界

Prompt 不是可靠的权限系统；长上下文不能保证模型使用了正确证据。

## 实现思路

固定规则与外部数据分层；按任务选择历史，必要时摘要并保留来源；设置输入预算；把关键业务约束交给代码执行。

## 练习

分别去掉无关历史、加入冲突文档和外部恶意指令，比较行为。

## 验收

任务依赖可解释；外部内容不能授权工具；摘要遗漏有检测方式；输入量可测量。
