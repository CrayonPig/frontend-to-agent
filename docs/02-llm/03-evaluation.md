# 评测：把不确定输出纳入回归

> 本页保留旧 URL 与原导读练习，作为迁移入口。完整正文已迁至：[07 答案看起来不错，怎么判断真的变好了](../02-verifiable/07-evaluation.md)、[19 RAG 评测：没找到，还是找到了却答错](../04-grounded/19-rag-evaluation.md)、[29 和固定工作流做一次公平对比](../06-agent/29-comparison.md)。以下是历史导读，不代表当前示例的覆盖范围；运行与验收以新正文为准。

## 场景与目标

改了一句 Prompt，常见问题变好了，少数权限问题却退化。

## 从前端经验出发

借鉴单元测试、集成测试与回归测试，建立固定任务集和版本对比。

## 类比的边界

不能仅按字符串相等评判开放回答，也不能把模型裁判当作绝对正确。

## 实现思路

分开测结构、事实、引用、拒答、权限与任务完成；确定性项用代码，开放项用明确评分规则与人工抽检；保留开发集与独立验证集。

## 练习

建立包含正常、无答案、歧义、越权与恶意输入的基线集。

## 验收

记录样本量、评分规则和失败明细；提示与模型版本可追溯；上线门槛在评测前定义。
