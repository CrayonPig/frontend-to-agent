## 精确缺口

- **详细大纲**：`docs/README.md` 是42项章节列表；不存在含每篇操作、观察结果、验收与五组观测成果的权威规划。
- **10**：概念与树形图存在，但没有连接实际 SDK 导出字段、平台查验与同一可运行任务的映射。
- **11**：代码手动创建 `atlas-rule-mock-1` generation，没有模型 HTTP 调用。只做依赖与类型检查，未实际发送 SDK 上报。Docker 只提供外链，没有完整准备、运行和排障步骤。

- **30**：有具体错误答案、时间线和本地规则测试，但没有命令主动注入同一任务失败、获取真实 SDK trace、定位和修复后再比较。
