# 成本：每个成功任务花了多少

> 本页保留旧 URL 与原导读练习，作为迁移入口。完整正文已迁至：[38 不是每次调用便宜，而是每次成功任务划算](../08-operations/38-cost.md)。以下是历史导读，不代表当前示例的覆盖范围；运行与验收以新正文为准。

## 场景与目标

换了便宜模型后，重试与工具调用增加，总费用反而上涨。

## 从前端经验出发

像管理包体积和资源预算一样，给上下文、输出、回合数和调用次数设置预算。

## 类比的边界

token 数不等于总成本；检索、工具、存储、重试与人工复核也有成本。

## 实现思路

记录输入输出用量、缓存用量和调用链；使用可配置且带生效日期的价格表；先做简单模型基线，再评测分层路由。

## 练习

用同一批问题比较两个方案的质量、总费用与成功任务数。

## 验收

给出总成本/成功任务数；失败费用计入分子；成功判定一致，价格来源可核对。
