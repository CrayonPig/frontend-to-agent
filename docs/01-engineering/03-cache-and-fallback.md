# 缓存与降级：速度之外的正确性

> 本章为学习导读与实践要求，后续补充可运行实现。

## 场景与目标

同一组件问题反复出现，但文档升级后旧答案还在命中。

## 从前端经验出发

借鉴 HTTP 缓存与 stale-while-revalidate，区分文档、检索结果与答案缓存。

## 类比的边界

语义相似不等于业务等价；私有内容不能跨用户复用；过期答案不一定可安全展示。

## 实现思路

按租户、权限范围、知识版本、模型与提示版本构造键；为每类缓存定义失效规则；降级可返回原文链接、限定能力或明确暂不可用。

## 练习

更新文档、撤销权限，再重复查询；模拟主模型不可用。

## 验收

不会命中越权结果；失效规则可复现；降级来源和能力范围对用户可见。
